01 — Problem Statement

The Current Manual Process Is Inefficient

The Economic Enterprise & Management Office currently relies on a fully manual collection workflow, causing data redundancy, human error, and delays in financial reporting.

✍️
Manual Re-Entry of Vendor Names
Collectors must re-write or re-type the name of each stall vendor every collection cycle, even though the vendor list is already known and fixed.
📋
Repetitive Data Entry
Each transaction requires manually filling in vendor name, stall number, date, type of fee (rental, electric bill, etc.), and amount — every single time.
⚠️
Prone to Human Error
Manual writing introduces misspellings, missed entries, and calculation mistakes that are hard to audit and correct after the fact.
📊
Delayed Financial Reporting
Without real-time recording, the office must wait for collectors to return and encode data before any summary or report can be generated.
🗂️
No Centralized Record
Collected data lives on paper forms that are difficult to search, archive, or cross-reference, making audits time-consuming and unreliable.
📉
No Visibility for the Office
Office supervisors have no way to monitor collection progress in real time — they are blind to who has paid and who has not until forms are returned.

02 — Proposed Solution

StallTrack: A Pre-Loaded, Check-and-Submit System

Instead of writing details from scratch, collectors open the mobile app, find the vendor from a pre-loaded list, tick the appropriate fees, enter the amount collected, and submit — in under a minute.

📱 Mobile App — For Collectors

1

Login & Select Facility

Collector logs in with assigned credentials (admin-created only), then selects a facility from the home menu — New Public Market, Town Center, Terminal, and more.

2

Pre-Loaded Stall List per Month

All registered stall vendors are already in the app. Supports search, filter (All / Permanent / Temporary / Paid / Unpaid), and shows the active collection month.

3

Status Picker: Paid / Partial / Unpaid

Tapping a stall opens a status picker. If Partial, the collector enters the exact amount collected and the remaining balance is computed automatically.

4

4-State Visual Checkboxes

Empty (not visited), Green ✓ (paid), Gold — (partial), Red ✗ (confirmed unpaid) — the collector knows at a glance who they have already approached.

5

Works Offline Anytime

All transactions are saved locally on the device using SQLite and queued for automatic sync when internet is restored.

🖥️ Web Dashboard — For the Office

1

Live Collection Dashboard

The office monitors real-time collection progress — who has paid, who is pending, and facility totals per billing month.

2

Manage Vendors, Stalls & Collector Accounts

Add, edit, or deactivate vendor and stall records. Create and manage collector login accounts. Changes sync to mobile instantly.

3

Reports: By Facility, By Day, Per Payee

Month-navigable reports showing facility totals, daily breakdowns, and per-payee balance tracking with delinquency status.

4

Per-Payee Balance Monitoring

Each payee shows monthly rate, months unpaid, total balance due, and last paid date — sorted by most overdue first for actionable follow-up.

04 — Offline-First Architecture

How the Offline Sync Works

Markets often have poor connectivity. StallTrack is built offline-first — collectors never lose data, and syncing happens automatically in the background when a connection is available.

📵 When Offline (No Internet)

1
App detects no internet connection on startup or during collection.
2
All transactions are recorded and saved in the local SQLite database on the device.
3
The app shows an "Offline — Data Queued" indicator so the collector knows the status.
4
The collector can continue working normally — no interruption in the collection process.
⇄
Connection
Restored

🌐 When Back Online (Internet Restored)

1
App automatically detects internet restoration in the background.
2
All queued SQLite records are batched and sent to the .NET Core API via HTTPS.
3
The API validates each record and writes them to PostgreSQL on the cloud server.
4
SQLite queue is cleared and the app shows a "Synced ✓" confirmation to the collector.
5
The Blazor web dashboard updates in real time — the office now sees the newly synced transactions.
📌 Note on Data Integrity:

Each transaction record includes a unique device-generated UUID, timestamp, and collector ID before being queued. This ensures that when multiple collectors sync simultaneously, there are no duplicates or data conflicts on the central database.

06 — Expected Impact

Key Benefits for the EEMO

StallTrack directly addresses each pain point in the current workflow, reducing administrative burden and improving financial transparency for the local government unit.

⚡

Faster Collections

Collectors no longer re-write names, dates, or stall numbers. A single collection is recorded in under a minute.

🎯

Reduced Human Error

Pre-loaded data eliminates misspellings and missed fields. Data entry is limited to variable fields only (amount, date status).

📡

Real-Time Visibility

The office monitors live collection progress without waiting for collectors to return and encode paper forms.

📶

Offline Resilience

Collections continue uninterrupted even in areas with poor connectivity. Data is never lost — only queued.

📊

Instant Reports

Financial summaries per vendor, per stall zone, per collector, or per billing period are generated automatically.

🔒

Secure Audit Trail

Every transaction is logged with the collector's identity and timestamp — enabling full accountability and auditability.

📂

Centralized Records

All data is consolidated in one cloud database, eliminating paper forms and fragmented spreadsheets.

🔄

Scalable System

New stalls, vendors, fee types, or collectors can be added at any time through the web dashboard — no code changes needed.

⚠️

Delinquency Detection

The Per Payee report automatically flags payors as Up to Date, Overdue (1–2 months), or Delinquent (3+ months) — sorted by worst cases first so the office knows exactly who to follow up on.

💰

Partial Payment Tracking

Partial payments are recorded with the exact amount collected. The remaining balance is automatically computed and visible in both the market stall list and collection record detail sheets.

🏛

Summary Statement

StallTrack transforms the EEMO's stall rental collection from a paper-based, error-prone manual process into a fast, digital, and data-driven system — accessible from the field on a mobile phone and from the office on a web browser, with automatic cloud synchronization and full offline support.
